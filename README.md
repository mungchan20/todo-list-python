# Todo List (Python)

콘솔 기반 To-Do 리스트 관리 프로그램입니다. Python 함수 기반으로 처음 작성한 뒤, 클래스 기반 구조로 리팩토링했습니다.

## 기능

- 할 일 추가
- 할 일 목록 조회
- 할 일 완료 처리
- 할 일 삭제

## 실행 방법

```bash
python todo.py
```

실행하면 메뉴가 표시되고, 번호를 입력해 각 기능을 사용할 수 있습니다.

## 사용 예시

```
1. 할 일 추가
2. 할 일 목록 보기
3. 할 일 완료 처리
4. 할 일 삭제
5. 종료

원하는 작업을 선택하세요:
```

## 개발 과정

처음에는 함수와 `while` 반복문만으로 구현했고, 이후 `TodoList` 클래스로 리팩토링하여 상태(할 일 목록)와 동작(추가/조회/완료/삭제)을 하나의 객체로 관리하도록 개선했습니다.

## 사용 기술

- Python 3
- 표준 라이브러리만 사용 (외부 의존성 없음)
